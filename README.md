# Sagers qAnalyzer

**SAGERS QUANT**

Trading-Analyseplattform für Strategie-, Portfolio- und Risikoanalyse.

---

## Ziel

Der Sagers qAnalyzer liest Trading-Daten (CSV, Excel, später Datenbanken) ein
und erstellt daraus Kennzahlen, Charts und Risikoanalysen – einzeln pro
Strategie und kombiniert als Portfolio.
